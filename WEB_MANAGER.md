# Web Manager

## Duties 

1. Manage the website regularly, checking its functionality
2. Keep website current with updated information
3. Track usage of the site and provide a monthly report

## Automation

Every Monday morning, a [GitHub Issue](https://github.com/mn-area35-d08/public-website/issues) will be created.
The Issue serves as a reminder to check the website and includes a suggested list of tasks.

- See the [Issues](https://github.com/mn-area35-d08/public-website/issues) tab.
- See the automation code at [weekly-web-check.yml](.github/workflows/weekly-web-check.yml)
